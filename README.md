# Bulldog Septic - Terrebonne, Oregon Website Preview

Five-page static sales mockup for Bulldog Septic in Terrebonne, Oregon.

## Pages
- Home
- Septic Pumping
- Septic Repair
- Installation & Replacement
- Contact

## Cloudflare Pages
Use:
- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

## Preview safeguards
The site is intentionally noindex while it is a sales preview. Remove the robots block and noindex meta tags before a real client launch.

The contact form is visual-only until the owner confirms where submissions should be delivered.

Public business details used for this mockup should be confirmed by Bulldog Septic before a production launch.
